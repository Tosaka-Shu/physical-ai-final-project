# システム設計

## 構成と単位

Python 3.12、CPU、GUI不要。25×20セル、1セル=1m、半径0.20m、車輪間隔0.40mの差動二輪ロボットを連続座標で積分する。時間刻み0.1秒。最大前進速度0.9m/s、角速度2rad/s。基地(2,10)から避難所(22,10)まで配送する。

world.pyは壁・瓦礫・狭路と正弦運動する円障害物、robot.pyは左右車輪速度から円弧を積分、sensors.pyは距離センサーとAI特徴量、planner.pyは4近傍A*、simulation.pyは制御・安全判定・再計画、visualization.pyは実走行ログの描画を担当する。

## AIとデータ

RandomForestClassifier、100木、深さ12、最小葉4、乱数42、CPU並列2。
特徴は静的障害物距離、横方向の通路幅、最寄り移動物体距離・接近速度・前後位置・横位置、速度、進行方向cos/sinの9成分。
異なる瓦礫配置と移動物体位相のシナリオから、位置・方向・速度・時刻をサンプリングする。1.5秒間の直進を16時点で模擬し、障害物表面への距離が0.38m未満なら危険ラベル1とする（半径0.20m＋余裕0.18m）。

学習シナリオ0–29（5400例）、モデル評価100–109（1800例）、配送比較200–202を分離。行単位のランダム分割を行わない。評価精度はdocs/model_metrics.json参照。衝突とニアミスを統合した教師ラベルであり、実環境で校正された衝突確率ではない。

## 経路と安全

通常A*は各移動コスト1、AI A*は `1 + 8 * predict_proba(features)[1]`。マンハッタン距離をヒューリスティックに使う。方向別に候補セルの特徴を計算し、現在時刻・速度0.9m/sを仮定した確率をバッチ推論する。到着時刻の将来予測は未実装。

近傍の経路4セルに移動物体が接近したら最大3秒に1回再計画。危険なセルを一時的に除外する。近傍8方向の距離センサーは0.5秒ごとに観測しログへ保存する。現段階の安全制御と経路計画は完全な世界状態を使い、センサーのみの自律認識ではない。

衝突防止はAIと独立。次の0.1秒の移動区間を5点で確認し、静的壁に対して半径＋0.03m、移動物体に対して半径和＋最大移動量＋0.03mを確保できなければ前進を停止する。回転は可能。移動障害物側にも、ロボットへ進入しそうな場合はその刻みだけ位相進行を止める譲り合い制御がある。この制約は両方式に共通だが、ロボット軌跡に応じて障害物軌跡も変わりうる。同一シードは同じ初期状態と制御規則を意味し、完全に同じ外生的軌跡を保証しない。

衝突回数は重なりを検出したステップ数、ニアミスは表面間余裕0.18m未満への進入回数、走行距離は実移動の和、再計画回数は再計画を試みた回数。180秒で打ち切り。配送成功はゴール中心から0.2m未満。

## 独自の工夫と制約

短い狭路と長い広路を同じ地図に配置し、AIコストが経路を変えることをテストする。AIと独立した安全層、シナリオ分割、実走行ログからの動画再生を用意した。
合成地図の多様性は限定的で、主要な壁構造は固定。物理エンジン、車輪の滑り、荷物、SLAM、実センサー雑音は未モデル化。全周距離センサーは観測用であり制御への統合は今後の課題。動画ヒートマップは初期時刻・東向きの参考値で、実際のA*は方向ごとに異なる危険度を使用する。
