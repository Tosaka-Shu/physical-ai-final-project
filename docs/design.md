# 配送システム設計

## 観測・推論・制御

Worldは真値を保持する。Lidarは静的壁と動的円の最初の交点だけを返し、ObservedMapは既知の静的地図と検出履歴を保持する。planner・features・safetyはWorldを入力に取らない。物体の未来位置関数はラベル生成と評価器だけが参照する。

10特徴量は壁距離、通路幅、観測物体距離、接近速度、前方相対位置、横距離、候補速度、cos方向、sin方向、前方地図距離である。整数候補位置の静的な距離特徴だけをキャッシュし、観測地図変更時に全消去する。動的特徴は時々刻々再計算する。

## 学習と探索

RFは80木、最小葉4、乱数42、深さ8/12の検証選択。独立した6シナリオでisotonic校正を学習し、別の検証集合のBrier scoreで採否を選ぶ。分類診断テストは過去にも使用した集合で、未知配送評価とは区別する。

4近傍A*は非負の危険度加算コストを使う。辺コストは1以上なのでマンハッタン距離は許容的・整合的である。有限マップ上で改善されたコストだけをキューへ追加し、古いキュー項目を破棄する。重み0では推論を省略する。低リスク域の抑制閾値0.4と重み2は、30環境の配送検証で選択を確認した。ルール方式は独立に重み0.5を選択した。局所リスクの総和は経路衝突確率とは扱わない。

## 共通安全制御と再計画

全方式が、同じ2.5秒等速予測領域と独立安全ゲートを使う。0.25秒超の指令・観測、非有限値、モデル異常は停止する。壁の掃引余裕0.035m、観測移動円の余裕0.12m、近接距離0.26mの閾値を維持する。衝突は真値評価器が検出し即終了する。停止中に物体が進入する衝突は防げるとは限らない。

地図更新、経路上の接近、経路消失で再計画する。3秒で0.15m進まなければ先頭2セルを一時回避し、迂回不能なら元の条件で再試行する。最大2秒ごとの再計画制限、動的到達不能の最大5秒待機、180秒の時間制限を共通に使う。

## 評価と再生

crossing 20000–20199、clutter 30000–30199、closure 40000–40199の600組を固定し、各方式で同一環境を使用する。安全配送は成功かつ衝突・ニアミス0。失敗を除外せず、失敗時180秒の時間指標も記録する。AIとルール方式をそれぞれ30開発組・6回帰組で独立調整し、最終テストを選択に使わない。正確McNemar両側検定の2比較へHolm補正、シナリオ内の対応ブートストラップを使う。検定と主評価項目・標本数は事前固定する。4プロセスの実行壁時計時間と各プロセスCPU時間を区別し、計算時間を仮想時間へ反映しない。

JSONLは更新前の観測・姿勢、要求指令、安全ゲート後の指令、更新後の姿勢と評価結果を同じ刻みで保存する。gzip版も同じ品質検査を通す。動画はログ再生で描画し、OP・EDの素材をアスペクト比維持で結合する。PDF・グラフ・数表は同じ集計JSONから生成する。
