# 検証

pytestは57件成功。既存の制御・学習・安全停止・ログ・PDF・音声あり/なし素材の結合テストを維持し、正確McNemar検定とHolm補正の既知例、同等データで優位性を主張しないこと、独立シード計画、欠損・重複の対比較データ拒否を追加検証する。

最終評価は600組・3方式・1,800走行。artifact_validation.jsonは全圧縮ログの品質検査、初期観測の方式間一致、成功・安全配送・衝突・ニアミス・距離・時間・停止・再計画・最小余裕・推論時間の再集計一致を記録する。

動画の構成、時間、音声方針、全体デコード検証はvideo_manifest.json。提供OP/ED、説明カード、事前指定したclosure・seed 40000、全600組の結果カードで構成する。説明資料は同じ集計JSONから原稿・グラフを生成し、全ページの表示を確認する。公開用PDFとID入り提出用PDFは同一内容で、後者はGit管理外とする。

57件のテストが通ることは実災害環境やすべてのシミュレーションでの安全保証ではない。最終評価に含まれる衝突・失敗をすべて記録し、統計的優位性を無条件に主張しない。
