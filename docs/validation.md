# 検証

pytestは53件成功。既存45件を維持し、静的特徴キャッシュの無効化、新環境の初期観測一致、重み0、ルール方式の確率範囲、gzipログ、音声付き/音声なし素材の結合、PDF生成を追加検証する。

最終比較は固定した90組・270走行。artifact_validation.jsonは全走行ログから成功、衝突、ニアミス、距離、時間、停止、再計画、最小余裕を再集計した結果を記録する。モデル選択と最終配送評価はシードを分離する。

完成動画の構成・時間・音声方針と全デコード結果はvideo_manifest.json。説明資料はreport_outline.mdから生成し、全ページ画像で表示を確認する。提出用のID入りPDFはGit管理外で公開用と同じ内容を保存する。
